Kundendatenbank Schulungen einrichten

Einmalige Einrichtung, etwa 30 Minuten. Danach läuft die App auf allen Macs, iPhones und iPads, synchronisiert in Echtzeit, und mehrere Personen können gleichzeitig arbeiten.

1Supabase-Projekt anlegen (die Datenbank)

ca. 5 Minuten · kostenlos

  1. Öffnen Sie supabase.com/dashboard und registrieren Sie sich (E-Mail und Passwort genügen).
  2. Klicken Sie auf New project.
  3. Name: z. B. kundendatenbank
  4. Database Password: auf Generate a password klicken und das Passwort sicher aufbewahren (wird im Alltag nicht gebraucht).
  5. Region: Central EU (Frankfurt) wählen. So bleiben die Daten in Deutschland.
  6. Create new project klicken und ca. 2 Minuten warten, bis das Projekt bereit ist.
Wichtig zum kostenlosen Tarif: Wird die Datenbank 7 Tage lang gar nicht benutzt, pausiert Supabase das Projekt. Ihre Daten bleiben erhalten, und im Dashboard holen Sie es mit Restore project zurück. Bei täglicher Nutzung passiert das nicht. Der Tarif Pro (ca. 25 $/Monat) pausiert nie und enthält tägliche Sicherungen.

2Tabellen anlegen

ca. 2 Minuten

  1. Links im Menü SQL Editor öffnen.
  2. Die Datei supabase-einrichtung.sql aus diesem Ordner mit TextEdit öffnen, alles markieren (⌘A) und kopieren (⌘C).
  3. Im SQL Editor einfügen (⌘V) und unten rechts auf Run klicken.
  4. Unten muss „Success. No rows returned“ erscheinen. Fragt Supabase nach einer Bestätigung („destructive operation“), mit Run this query bestätigen. Das Skript löscht keine Daten.

3Zugang absichern und Benutzer anlegen

ca. 3 Minuten

Fremde Registrierungen abschalten

  1. Links Authentication → Sign In / Providers öffnen.
  2. Allow new users to sign up ausschalten und speichern.
Dieser Schritt ist wichtig. Ohne ihn könnte sich jeder, der die Adresse Ihrer App kennt, ein eigenes Konto anlegen.

Ihren Benutzer anlegen

  1. Authentication → Users → Add user → Create new user.
  2. E-Mail-Adresse und ein sicheres Passwort eintragen und Auto Confirm User angehakt lassen.
  3. Für jede weitere Person (z. B. Mitarbeiter) einen eigenen Benutzer genauso anlegen.

4Verbindungsdaten in die App eintragen

ca. 3 Minuten

  1. In Supabase oben auf Connect klicken oder links Project Settings → API Keys öffnen.
  2. Diese zwei Werte kopieren:
    • Project URL, z. B. https://abcdefgh.supabase.co (unter Project Settings → Data API)
    • den Schlüssel anon public (Reiter Legacy API Keys, beginnt mit eyJ). Gibt es diesen Reiter nicht, nehmen Sie den Publishable key (beginnt mit sb_publishable_).
  3. Die Datei config.js mit TextEdit öffnen. Falls TextEdit Formatierungen zeigt: Menü Format → In reinen Text umwandeln.
  4. Die beiden Werte zwischen die Anführungszeichen setzen: 
    window.APP_CONFIG = {
  supabaseUrl: "https://abcdefgh.supabase.co",
  supabaseAnonKey: "eyJhbGciOi…"
};
  5. Speichern (⌘S).
Tragen Sie niemals den Schlüssel service_role bzw. Secret key ein. Der ist geheim. Der anon- bzw. Publishable-Schlüssel ist öffentlich und darf in der Datei stehen: Ohne Anmeldung sieht damit niemand Daten.

5App ins Internet stellen (Netlify)

ca. 5 Minuten · kostenlos

  1. app.netlify.com/signup öffnen und ein kostenloses Konto anlegen (E-Mail genügt).
  2. Dann app.netlify.com/drop öffnen und den ganzen Ordner kundendatenbank-app aus dem Finder in das Feld ziehen.
  3. Nach wenigen Sekunden erscheint eine Adresse wie https://zufallsname-123.netlify.app.
  4. Optional einen besseren Namen vergeben: Site configuration → Change site name, z. B. schulungen-franz. Die Adresse lautet dann https://schulungen-franz.netlify.app.

Adresse in Supabase eintragen (für „Passwort vergessen“)

  1. Supabase → Authentication → URL Configuration.
  2. Bei Site URL Ihre Netlify-Adresse eintragen und speichern.

6Auf Mac, iPhone und iPad installieren

je Gerät ca. 1 Minute

Mac (Safari, ab macOS Sonoma)

  1. Ihre App-Adresse in Safari öffnen.
  2. Menü Ablage → Zum Dock hinzufügen… → Hinzufügen.
  3. Die App startet nun aus dem Dock bzw. Launchpad in einem eigenen Fenster. Beim ersten Start einmal anmelden.

Mit Chrome oder Edge: in der Adresszeile auf das Installieren-Symbol klicken.

iPhone und iPad (Safari)

  1. Ihre App-Adresse in Safari öffnen.
  2. Auf das Teilen-Symbol (Quadrat mit Pfeil) tippen → Zum Home-Bildschirm → Hinzufügen.
  3. Die App vom Home-Bildschirm starten und einmal anmelden. Die Anmeldung bleibt gespeichert.
Die App auf dem Home-Bildschirm bzw. im Dock hat eine eigene Anmeldung, getrennt von Safari. Melden Sie sich daher in der installierten App an, nicht nur im Browser.

7Im Alltag

  • Synchronisation: Änderungen erscheinen auf allen Geräten nach etwa einer Sekunde. Der grüne Punkt neben „Live synchronisiert“ zeigt die Verbindung an.
  • Gleichzeitiges Arbeiten: Bearbeiten zwei Personen denselben Termin, warnt die App beim Speichern und fragt, welche Fassung gelten soll. Nichts wird unbemerkt überschrieben.
  • Ohne Internet (z. B. beim Kunden im Funkloch): Die App zeigt die zuletzt geladenen Daten zum Nachschlagen an. Ändern geht erst wieder mit Verbindung.
  • Datensicherung: Machen Sie regelmäßig, z. B. monatlich, einen CSV-Export. Die Datei öffnet sich in Excel und Numbers. Im Pro-Tarif sichert Supabase zusätzlich täglich.
  • Neue Mitarbeiter: In Supabase unter Authentication → Users anlegen, wie in Schritt 3. Ausscheidende Mitarbeiter dort löschen.
  • Updates der App: Geänderte Dateien in den Ordner legen und den Ordner bei Netlify unter Deploys erneut in das Feld ziehen. Die Geräte übernehmen das Update beim nächsten Start.

iDatenschutz

  • Die Daten liegen in Frankfurt (EU). Supabase bietet einen Auftragsverarbeitungsvertrag (DPA) an: im Dashboard unter Organization Settings → Legal Documents. Für Kundendaten sollten Sie ihn abschließen.
  • Netlify liefert nur die Programmdateien aus. Ihre Kundendaten laufen nicht über Netlify.
  • Die App lädt keine Schriften oder Skripte von Fremdanbietern wie Google. Alles ist im Ordner enthalten.
  • Beim Abmelden wird die Lesekopie auf dem Gerät gelöscht.
