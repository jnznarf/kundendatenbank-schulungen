# Kundendatenbank Schulungen

Web-App (PWA) zur Verwaltung von Kunden und Schulungsterminen mit Bericht,
Schulungsbescheinigungen, Rechnungslegung und Übersicht der offenen ToDos.
Daten in Supabase (Postgres, Region Frankfurt) mit Echtzeit-Synchronisation
zwischen Mac, iPhone und iPad.

- Einrichtung: siehe `ANLEITUNG.html` (im Browser öffnen)
- Datenbank-Schema: `supabase-einrichtung.sql`
- Verbindungsdaten: `config.js`
- Veröffentlichung: Netlify, automatisch bei jedem Push auf `main`
